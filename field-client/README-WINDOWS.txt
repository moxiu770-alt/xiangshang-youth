向上少年 Windows 场地端 0.4.27
================================

适用系统：Windows 10/11 64 位
安装方式：绿色自包含版，无需安装 .NET SDK，也不要运行任何 .ps1 文件。

首次使用
1. 将整个压缩包解压到固定目录，不要直接在压缩包里运行。
2. 双击 FieldClient.Windows.exe。
3. 首次启动会自动打开“连接场地端”。
4. 在管理后台“场地中控 > 部署与设备配置”中注册设备。
5. 在后台点击“一次复制三项接入信息（含密钥）”，然后在客户端点击“从剪贴板粘贴”。也可以逐项复制服务器地址、设备 ID、设备密钥。
6. 点击“测试并保存”。连接成功后会清除匹配的密钥剪贴板内容，之后直接双击 EXE 即可。
7. 若项目已交付厂商采集适配器，将厂商整个文件夹复制到“采集适配器”。主界面开测条件卡片会直接显示“接入采集设备”，点击后选择 DLL 并“测试并保存”。客户端会自动识别类型，不需要设置环境变量。

注意事项
- 如果客户端电脑和服务器不是同一台电脑，服务器地址不能填写 localhost；请填写客户端能够访问的局域网 IP 或正式域名。
- 设备密钥只在后台注册或轮换时显示一次，请勿通过截图或聊天群传播。
- 一次复制的接入信息包含设备密钥，只应直接粘贴到场地端；不要粘贴到聊天软件或文档。
- Windows SmartScreen 可能提示“未知发布者”。当前为内部验收版，确认文件来自学校服务器并核对后台显示的 SHA-256 后，可选择“更多信息 > 仍要运行”。正式交付前应使用机构代码签名证书签名。
- 安装包默认不包含任何硬件厂商 DLL。未安装经过认证的相机/计时器适配器时，界面可以打开并同步名单，但正式采集会被开测检查锁定，不能用人工分数代替。
- 正式采集中，主界面会实时显示当前项目、设备提示、动作进度、置信度、事件数量和最近反馈时间；不要只凭设备厂商窗口判断采集是否仍在运行。
- 长名单可点击右侧“定位下一位”或按 F6 自动选中本站下一名候测学生；定位不会自动叫号，仍需人工核对后按 F2。
- 后台安全关闭当前任务后，客户端会停止叫号和采集；若有下一项已发布任务则自动切换，并明确提示现场人员重新核对名单。
- 后台将测试点设为“暂停”“维护”或“停用”后，设备心跳不会自行覆盖该状态；场地端会锁定新操作并显示具体原因。恢复时由后台改为“恢复待连接”，下一次有效心跳会自动上线。

排障
- 显示“本站尚未分配学生”：任务里已经有学生，但尚未分流到当前测试点；请让管理员在后台“现场运行”中选择任务，点击“生成 / 重新分流”，然后回到客户端刷新。
- 显示“本站当前没有学生”：现场学生已分配到其他测试点；请在后台检查本站测试能力、队列容量，或手工调整学生分配。
- 看不到连接窗口：直接点击主界面顶部“连接设置”；离线时按钮会显示为“恢复连接”或“立即连接”。
- 显示无法连接：先在浏览器中打开服务器地址，确认 Windows 与服务器网络互通。
- 密钥丢失：在后台对应设备上执行“轮换密钥”，再将新密钥填入客户端；旧密钥会立即失效。
- 显示“设备未接入”：点击右侧开测条件中的“接入采集设备”，选择项目交付方提供的 DLL。必须复制厂商整个目录，缺少依赖文件会导致识别或加载失败。
- 不要安装 .NET SDK，不要执行 dotnet run，不要从源码目录启动。
